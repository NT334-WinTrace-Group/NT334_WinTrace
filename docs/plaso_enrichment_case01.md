# CASE01: targeted Plaso evidence enrichment

The optional Manual Review panel uses a separate read-only Plaso database. It links existing Jump List anchors to exact full-path Office File MRU items within ±300 seconds using the embedded item FILETIME, not key LastWrite. Executable UserAssist matches must share the MRU source hive path and be within 300 seconds of both anchor and MRU item. Application extension mapping is a search hint; matching MRU is required. No drive alias inference, user attribution, new findings, confidence changes or validation promotion. Deduplication is conservative within the selected candidate (source path, item/document or executable, timestamp); it is not physical-artifact independence proof. Operator must confirm same acquisition. JSON export is separate from canonical HTML reporting.

CASE01 baseline: 692 events, 6,198 automated candidates. Extended timeline: 212,756 valid events. UserAssist extraction: 44 records. Selected raw checks: 9 UserAssist records matched; three Office File MRU keys and five item values matched (key timestamp tolerance 1 microsecond). C1, C2 and C5 have complementary application and document context; no new exfiltration or deletion conclusion. C6 cleanup and USB/Registry context remain separate manual analysis. This feature supports the specific Plaso export formats tested; other Office versions, MRU formats, registry hive naming and acquisition provenance require further validation. Do not commit raw logs, database or output JSON.
